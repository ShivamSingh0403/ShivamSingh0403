## 🎮 Interactive Zone

<details>
<summary>🧩 1. Guess the Output</summary>

```js
console.log(1 + "1");
console.log(1 - "1");
```

**Choices:** A) `11, 0`  B) `2, 0`  C) `11, NaN`  D) `NaN, NaN`

<details><summary>Answer</summary>

**A) 11, 0**

`+` triggers string concatenation when one operand is a string, while `-` forces numeric coercion.
</details>
</details>

<details>
<summary>🌀 2. Escape the Infinite Loop</summary>

```js
let i = 0;
while (i < 5) {
  console.log(i);
}
```

**Choices:** A) Add `i++` inside the loop  B) Change `while` to `for`  C) Add `break`  D) Nothing needed

<details><summary>Answer</summary>

**A) Add `i++` inside the loop**

`i` never changes, so the condition `i < 5` is always true — a classic infinite loop.
</details>
</details>

<details>
<summary>🐛 3. Find the Bug</summary>

```js
function add(a, b) {
  return a + b;
}
add(2);
```

**Choices:** A) Missing return  B) `b` is undefined  C) Wrong function name  D) No bug

<details><summary>Answer</summary>

**B) `b` is undefined**

Calling `add(2)` leaves `b` as `undefined`, so the result becomes `NaN`.
</details>
</details>

<details>
<summary>🛠️ 4. Fix the Syntax</summary>

```js
function greet() {
  console.log("Hello")
}
```

**Choices:** A) Missing semicolon after `console.log("Hello")`  B) Nothing is wrong  C) Missing `return`  D) Wrong brackets

<details><summary>Answer</summary>

**B) Nothing is wrong**

JavaScript's automatic semicolon insertion makes this valid, though adding one is good style.
</details>
</details>

<summary>🧠 5. Memory Challenge</summary>

**Question:** Which data structure uses LIFO (Last In, First Out)?

**Choices:** A) Queue  B) Stack  C) Array  D) Linked List

<details><summary>Answer</summary>

**B) Stack**

A stack pushes and pops from the same end, so the last element added is the first removed.
</details>
</details>

```python
def divide(a, b):

print(divide(10, 0))
```

**Choices:** A) SyntaxError  B) ZeroDivisionError  C) Returns 0  D) Returns infinity

<details><summary>Answer</summary>

**B) ZeroDivisionError**

Python raises this exception whenever the denominator is zero.
</details>
</details>

It's designed specifically for shortest-path problems on graphs with non-negative weights.

<summary>🔢 8. Binary Quiz</summary>

**Question:** What is the decimal value of binary `1010`?

**Choices:** A) 8  B) 9  C) 10  D) 12

<details><summary>Answer</summary>

**C) 10**

`1010` = (1×8) + (0×4) + (1×2) + (0×1) = 10.

**Question:** Which header is required to use `printf()` in C?

**Choices:** A) `<string.h>`  B) `<stdio.h>`  C) `<stdlib.h>`  D) `<math.h>`

<details><summary>Answer</summary>

**B) &lt;stdio.h&gt;**

This header declares the standard input/output functions like `printf` and `scanf`.

<details><summary>Answer</summary>

**B) useState**

It returns a state variable and a setter function to update it.
</details>

<summary>🏷️ 12. HTML Quiz</summary>

**Question:** Which tag is used to embed a scalable vector graphic?

**Choices:** A) `<img>`  B) `<svg>`  C) `<canvas>`  D) `<vector>`

<details><summary>Answer</summary>

**B) &lt;svg&gt;**

`<svg>` renders vector graphics directly in the DOM, unlike `<img>` which just references a file.
